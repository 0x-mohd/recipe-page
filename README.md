🍳 Recipe Page

A simple and responsive Recipe Page built with HTML and CSS.

This project is based on a Frontend Mentor challenge, but I wanted to focus especially on the CSS details and make the page as close as possible to the original design.

🎨 CSS Highlights

I used CSS to create the complete visual style of the page, including:

🎨 Custom color variables using :root
✍️ Young Serif for headings and Outfit for the main text
📦 Flexbox for organizing the different sections
📱 Media queries for responsive design
🟣 Custom styling for lists and markers
📊 A clean nutrition table with borders and spacing
🧩 Different spacing, padding, and typography for each section
📐 A responsive recipe card that changes on smaller screens

I also created reusable CSS variables for colors, fonts, font weights, and line heights to keep the stylesheet organized and consistent.

📱 Responsive Design

The layout changes depending on the screen size.

On desktop, the recipe appears inside a centered card with rounded corners.

On mobile, the card takes the full width of the screen and the layout becomes simpler and more comfortable to read.

🛠️ Built With
HTML5
CSS3
Flexbox
CSS Custom Properties
Media Queries

💭 What I Learned

This project helped me understand that good CSS is not only about making things look good. Small details such as spacing, typography, colors, borders, and responsive behavior can make a big difference in the final design.

It was a small project, but a great opportunity to improve my CSS skills. 🚀
